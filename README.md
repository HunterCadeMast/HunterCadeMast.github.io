# Hunter Mast Terminal Portfolio @ https://huntercademast.github.io/

An **terminal-simulated portfolio website** showcasing my projects, experience, and contact info in a command-line interface.
This project replicates a terminal experience using **HTML, CSS, and JavaScript**, complete with ASCII art, typing animation, and command execution.

🌐 Live Site: https://huntercademast.github.io/

---

## 📌 Project Overview

The terminal portfolio provides a nostalgic **terminal interface** while presenting information about myself and my work.

Users can type commands to:
- Learn about me (`about`).
- View my professional experience (`experience`).
- Access my social profiles (`socials`).
- Explore my projects (`projects` / `project[1-3]`).
- Clear the terminal (`clear`).
- Navigate command history with **Arrow Up/Down**.

The design simulates a terminal with:
- Typing animations for realistic terminal simulation.
- **Comodore64 font** for a retro aesthetic.
- Colored ASCII graphic.

---

## 🖥️ Features

- Retro terminal UI with **ASCII art**.
- Typing animation for all outputs.
- Interactive commands with real-time responses.
- Command history support.
- Full-screen responsive design.

## 💻 Command Reference

| Command       | Description                                                   |
|---------------|---------------------------------------------------------------|
| `help`        | Displays all available commands                               |
| `about`       | Learn more about Hunter Mast                                  |
| `socials`     | Shows LinkedIn and GitHub profiles                            |
| `email`       | Displays my email address                                     |
| `experience`  | Shows my professional experience and skills                   |
| `projects`    | Lists all projects                                            |
| `project1`    | Details about **Quantum Ray Tracer**                          |
| `project2`    | Details about **Automated Farming Simulator**                 |
| `project3`    | Details about **Dynamic Emotion Recognition Software**        |
| `previous`    | Displays previously entered commands                          |
| `clear`       | Clears the terminal                                           |
| `welcome`     | Re-displays the ASCII welcome message                         |
